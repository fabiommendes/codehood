Bem-vindas e bem-vindos a Introdução à Programação com Python e Jogos.

Para a primeira aula, instale o Python 3.11 ou mais novo e o Pyxel (as
instruções estão nas notas da aula 1). Se algo der errado, traga a mensagem de
erro para o atendimento de quarta-feira, das 16h às 18h.

Cada laboratório é um repositório de git. Para clonar o primeiro:

```bash
git clone <endereço do repositório lab01-janela>
cd lab01-janela
python -m pytest
```

Os testes falham de início, e o trabalho é fazê-los passar. O endereço de cada
repositório está no cronograma, na página do laboratório.
