O que o programa abaixo imprime?

```python
print(type(10 / 5))
```

* [ ] `<class 'int'>`
  > A divisão `/` sempre devolve `float`, mesmo quando o resultado é exato. Para
  > obter inteiro, use `//`.
* [*] `<class 'float'>`
  > `10 / 5` vale `2.0`. O operador `/` produz `float` sempre.
* [ ] `<class 'str'>`
  > Nenhuma operação aritmética produz texto sozinha.
* [ ] `<class 'number'>`
  > O Python não tem um tipo chamado `number`.
