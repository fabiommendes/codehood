Quais dos nomes abaixo são identificadores válidos em Python 3?

* [x] `pontos_1`
* [ ] `1o_pontos`
  > Um nome não pode começar com dígito.
* [ ] `jogador-x`
  > O hífen é lido como subtração: `jogador - x`.
* [x] `_vidas`
  > O sublinhado inicial é válido e, por convenção, indica uso interno.
* [ ] `for`
  > `for` é palavra reservada e não pode ser usada como nome.
* [x] `pontuação`
  > O Python 3 aceita letras acentuadas em nomes, mas nos programas é mais seguro evitá-las.
