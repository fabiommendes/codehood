---
title: Índice negativo
tags: [listas, indices]
locale: pt-BR
domain: integer
incorrectFeedback: Índices negativos contam do fim. `values[-1]` é o último elemento, então `values[-2]` é o penúltimo.
---

Qual valor o programa abaixo imprime?

```python
values = [10, 20, 30, 40, 50]
print(values[-2])
```

[numeric]: 40
