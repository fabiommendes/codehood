# Rubrica do projeto final

A versão completa, com os níveis de cada critério, está em `resources/projeto/rubrica.md`
nos materiais da disciplina. Este resumo segue os mesmos pesos.

Cada critério vai de 0 a 10 e a nota do projeto é a soma ponderada.

| Critério | Peso | Nota máxima quando |
| :-- | --: | :-- |
| Jogo | 35% | Tem título, jogo e fim; os requisitos obrigatórios funcionam do início ao fim sem travar. |
| Código | 25% | Lógica separada do Pyxel em funções e classes, nomes claros. |
| Testes | 15% | Pelo menos 5 testes úteis de pytest, que passam. |
| Git | 15% | Todos os integrantes têm commits e há ramos por tarefa. |
| Apresentação | 10% | 8 minutos, demonstração ao vivo e divisão do trabalho. |

A nota é individual: ela é reduzida, proporcionalmente, para quem contribuiu com
menos de metade da média do grupo no histórico do git.
