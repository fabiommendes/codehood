# Introdução à Programação com Python e Jogos

Um primeiro curso de programação em que cada conceito aparece primeiro na tela:
variáveis viram coordenadas, laços viram padrões, listas viram inimigos e
classes viram a nave do jogador. Usamos Python e a biblioteca Pyxel, um motor
de jogos retrô com paleta de 16 cores e editor de sprites embutido. Não exige
experiência prévia. Ao final, cada grupo entrega um jogo completo.

## Avaliação

A nota final combina laboratórios, duas provas e o projeto final. Os pesos são:

| Componente                    | Peso |
| :---------------------------- | ---: |
| Laboratórios (9 entregas)     |  25% |
| Prova 1 (semana 7)            |  20% |
| Prova 2 (semana 15)           |  25% |
| Projeto final (em grupo)      |  30% |

- Os laboratórios são corrigidos automaticamente por testes. Um laboratório
  pode ser reenviado até o fim do semestre, com nota máxima de 70% depois do
  prazo.
- O quiz semanal de prática não vale nota. Serve para treinar o formato das
  provas.
- A prova de reposição substitui a menor nota entre Prova 1 e Prova 2, e só
  pode ser feita por quem perdeu uma delas com justificativa.
- O resultado final é `aprovado` ou `reprovado`. Está aprovado quem tem média
  final de 50 ou mais (de 0 a 100) e frequência de pelo menos 75%.

## Política

- Frequência mínima de 75% das aulas. A presença é registrada nas aulas de
  terça e de quinta, e o atendimento de quarta não conta.
- Laboratórios e provas são individuais. Conversar sobre
  a ideia é permitido, copiar código não é. Cópias entre colegas ou de
  repositórios públicos zeram a entrega.
- Ferramentas de geração de código podem ser usadas para estudar, mas nas
  provas não são permitidas. Cite no README do laboratório qualquer ajuda
  externa relevante.
- No projeto final, a divisão do trabalho entre os integrantes deve ficar
  visível no histórico do git.
- Atendimento às quartas, das 16h às 18h, sem necessidade de marcar horário.
