# Spec folder

This folder contains specifications for features and functionality of the 
application. Each spec is a markdown file that describes the expected behavior 
of a feature, including requirements, design decisions, and any relevant context.

Specs are organized into subfolders based on their status:

* `to-do`: Specs that are planned but not yet implemented.
* `to-review`: Specs that have been implemented and are awaiting review.

Once review is complete and the spec is approved, the spec file is simply 
deleted. Use git history to recover some old specs, if needed.
