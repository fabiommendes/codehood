# Roadmap

This describes the roadmap for the near future development of the Codehood
server. It is a living document and will be updated as new features are planned
and implemented.

Once a milestone is reached, move the corresponding items to the changelog and 
delete them from this file.


## 0.1.0

* Basic Web app functionality:
  - [ ] Display courses and assignments.
  - [ ] Support for basic question types (multiple choice, short answer).


## 0.2.0

* Implements basic interaction with the CLI tool
  - [ ] Upload new assignments to the server.
  - [ ] Syncronize local and remote assignment data (updating and deleting).
  - [ ] Collect student submissions and grades from the server.
