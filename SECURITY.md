# Security policy

Codehood stores grades, submissions and personal data of students. A flaw that
lets a user read or change data outside their own courses, or act as another
user, is a security problem.

## Supported versions

Only the latest commit on `main` receives security fixes.

## Report a vulnerability

Do not open a public issue. Use
[private vulnerability reporting](https://github.com/fabiommendes/codehood/security/advisories/new)
on GitHub instead. Include the steps to reproduce the problem and say whether
it affects the server, the CLI (`cli/`) or both.
